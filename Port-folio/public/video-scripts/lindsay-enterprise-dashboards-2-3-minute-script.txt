The difficult part of an executive dashboard isn't drawing a chart. It's making sure leadership can answer recurring questions from a trusted data layer, without asking engineering for another one-off query. That trust is what turns reporting into a dependable operating tool. That was the opportunity at Lindsay. The organization already had refined data moving through a Medallion architecture, but sales, supplier, and IT questions didn't have consolidated leadership views. Each new question could become another ad-hoc request, which slowed the path from data to a decision. I built a set of leadership-facing dashboards directly on the governed Gold layer. The architecture starts with Bronze-to-Gold refined data registered through Unity Catalog. From that common foundation, Databricks AI/BI supports interactive exploration, while Power BI provides a familiar distribution channel for broader reporting. Both paths lead to the same audience and the same governed data products. My work covered three business areas. For sales, I created views of revenue and order performance. For suppliers, I exposed supplier-performance and delivery metrics. For IT, I organized operational key performance indicators for the technology organization. The goal wasn't to create isolated reports. It was to turn one refined layer into reusable views that answered different leadership questions consistently. Governance was part of the design, not an afterthought. Because the dashboards were backed by Unity Catalog, access control and lineage stayed with the underlying data. The presentation layer didn't need its own unmanaged storage credentials or a separate definition of ownership. I also used the two BI experiences deliberately: Databricks AI/BI for direct, interactive work on the Gold layer, and Power BI for distributed consumption. The result is an in-production dashboard set that gives leadership consolidated views across sales, supplier, and IT operations. The portfolio record doesn't claim a specific time-saving percentage or dashboard count for this project, so I won't invent one. The value is the operating model: governed Gold data becomes decision-ready information through two complementary BI channels, with a clearer path from a business question to an answer.
