This project turned a star-schema warehouse into a connected suite of operational Power BI dashboards. Before the suite, field representatives and operations managers relied on spreadsheets and separate report extracts. There was no shared view of shelf life, inventory gaps, visit coverage, quality issues, or merchandising compliance, and a circulated report could already be behind what had changed in the store.

I built one semantic model on top of the SQL Server data warehouse rather than creating a separate model for every report. Shared DAX measures defined common calculations once, so a corrected measure flowed consistently across the complete suite. Power Query handled model preparation, and scheduled refresh kept the model connected to the warehouse.

On that foundation, I built seven dashboards, each focused on a specific operational question. Code Date tracked product shelf life. Rep Store Visits covered field activity and visit coverage. Low Stock and Out of Stock surfaced inventory gaps by store. Quality and Credits followed quality issues and credit activity. Planogram focused on merchandising compliance. Missing Tags identified shelf-tag gaps. Hot Tags and Error Items highlighted priority and exception items.

The dashboards were designed as related views, not isolated files. Users could drill from region to store and then to item, allowing the same information model to support leadership summaries and detailed field investigation. Row-level security used DAX to scope each representative to their own stores, while operations, quality teams, and leadership could work at the level appropriate to their responsibilities.

Automated refresh and scheduled delivery replaced the recurring need to run and distribute reports manually. Because all seven dashboards shared the same semantic layer, model maintenance was centralized: a measure fixed once was fixed everywhere that used it.

My contribution covered the semantic model, shared DAX measures, Power Query preparation, row-level security, drill-down experience, scheduled refresh, delivery, and the seven operational dashboards themselves. The verified quantitative scope in the portfolio is seven dashboards on one star schema; no adoption or time-saving metric is documented. The outcome was a consistent self-service reporting layer for field reps, operations, quality, and leadership, with the same governed definitions available from high-level summaries down to individual store and item exceptions.
